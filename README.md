## 🚀 Projetos em destaque

### 📋 Automação JotForm → Secretaria (Power Automate)

Fluxo de produção que encaminha automaticamente submissões do JotForm (Matrícula, Ficha Médica, Atividades Extracurriculares, Solicitação de Bolsa) para a Secretaria da EWRS por e-mail, incluindo o tratamento de anexos obrigatórios e condicionais. Principais contribuições: tratamento de redirecionamentos HTTP 302 (padrão Initialize Variable + Condition) para contornar limitações do conector nativo do JotForm; correção do mapeamento de campos, já que o conector atribui numeração sequencial própria, divergente dos QIDs internos do JotForm; e projeto de um child flow reutilizável para lidar com redirecionamentos entre domínios de forma centralizada.
